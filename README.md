# 词汇回忆室

一个本地优先的英语词汇主动回忆工具。它把“看英文、回忆中文、再揭晓答案”作为主要学习流程，并用清晰的间隔复习节点帮助用户持续巩固生词。

项目最初来自我自己的词汇复习需求：词多以后，手工录入、辨认薄弱词、追踪历史进度都很麻烦。因此，我将拍照识别、自动补充释义、分级复习、进度记录和 PDF 导出整合进了同一个简洁界面。

## 功能亮点

- 英文 → 中文主动回忆，点击后显示答案
- “熟悉 / 模糊 / 不会”三档反馈
- 12 小时、1 天、3 天、7 天的固定间隔复习
- 随机打乱学习队列，避免依赖原始顺序
- 自动保存学习进度和每个单词的复习记录
- 连续 3 次选择“熟悉”后进入“长期记忆库”，不再重复出现
- 模糊和不会的单词继续进入后续复习
- 本地照片 OCR 批量识别英文单词和同行勾数
- 勾数达到 3 个自动移入长期记忆库，0～2 个勾继续复习
- 新词使用现有词库和本地 ECDICT 数据补义，并优先保留常见阅读、翻译考义
- 照片结果支持逐行纠正勾数、单词和中文释义
- 确认照片结果后，可直接导出本批待复习词汇 PDF
- 支持 CSV 批量导入，以及 JSON 进度备份和恢复
- 一键导出“连续熟悉少于 3 次”的待加强词汇双栏 PDF
- 一键导出长期记忆库的紧凑双栏 PDF
- 预置并合并 213 个英语词汇

## 数据与隐私

学习进度默认保存在当前浏览器中，照片识别和词典查询也在本机完成。项目不要求注册账号，不会把用户的词汇记录或照片上传到服务器。

清除 `http://localhost:3000/` 的网站数据会同时清除本地学习进度。建议定期使用应用内的 JSON 备份功能。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000/](http://localhost:3000/) 即可使用。

完整检查：

```bash
npm test
```

## macOS 长期运行

第一次使用时双击 `安装长期运行.command`。安装后，程序会在 Mac 登录时自动启动，后台意外退出后也会自动恢复，无需一直保留终端窗口。

平时双击 `启动背词程序.command` 即可打开；如需停用自动运行，可双击 `停止长期运行.command`。

## 技术栈

- React + TypeScript
- Vinext / Vite
- Tesseract.js 本地 OCR
- ECDICT 本地词典
- jsPDF 文档导出
- 浏览器本地存储

## 设计取舍

这是一个为真实个人学习流程定制的轻量工具，没有引入复杂的账号、云同步或完整 FSRS 系统。固定复习节点更直观，三档反馈也比传统四档评分更容易在日常复习中快速使用。
