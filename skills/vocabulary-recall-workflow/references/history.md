# 项目历史与文件定位

这是一份供后续 Agent 快速定位的决策摘要，不是原始聊天备份。用户的新要求始终优先。文件路径只代表建立本记录时的本机位置；访问前先检查是否仍存在。

## 需求演变

1. 最初基于 `Spaced_Repetition_Vocabulary-v2.pdf` 的 81 个待掌握词设计本地词汇回忆程序。目标是英文到中文的主动回忆，而不是拼写考试。
2. 用户希望长期使用，于是要求自动保存学习历史、查看薄弱词、12H/1D/3D/7D 间隔复习、到期复习不重置阶段，以及可备份的数据。
3. 后续增加照片批量识别与新词释义、人工核对、长期记忆库和 PDF 导出。用户最终将纸质勾选入库门槛从“≥2”改为“≥3”；程序评分的连续熟悉条件也为 3 次，但还要求通过 7D。
4. 词表成品多次调整为不带“考研”的标题、双栏英文/中文、适合背诵的行距、无状态栏、日期在右上角。新增批次与旧批次是否合并，以当次要求为准。
5. 2026-10-04：对一份 193 词的“本次新增”打印表，从三张照片逐行核对勾数；≥3 勾剔除 82 词，保留 111 词，保持原顺序与释义，生成两页 PDF。该次处理的是这份 193 词表，不是更早的全部词库。
